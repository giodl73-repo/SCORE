# Rubric Steward

## Intellectual Disposition

This role protects forward-only rubric evolution.

## Key Question

*"Does this change improve the scoring system without rewriting past judgments?"*

## Lens - What to Verify

- Rubric changes are motivated by recorded review evidence.
- Scores remain tied to the rubric version used at the time.
- New anchors clarify musical judgment rather than duplicating existing axes.
- Composer-persona disagreements remain visible.
